# JS Quest — приборкай багів

Пригодницька гра-тренажер JavaScript: 96 рівнів, 11 локацій, піксельний світ, що відновлюється з кожною пройденою темою.

**Стек:** чистий HTML/CSS/JS, без фреймворків і без збірки. Відкрий `index.html` у браузері (працює і через `file://`) або опублікуй репозиторій через GitHub Pages.

## Як грати

- **Карта** — 11 локацій з'єднані стежкою. Пройдені позначені галочкою, поточна — «Ти тут», закриті — замком. Клік по локації відкриває список її місій.
- **Місія** — легенда, завдання і чеклист ліворуч, редактор/відповідь по центру, сцена праворуч. `Ctrl+Enter` запускає код.
- Помилки не караються: наставник підказує, а після трьох спроб пропонує подивитися рішення.
- Прогрес (пройдені рівні, XP, серія з першої спроби, трофеї) і чернетки коду зберігаються в `localStorage` (ключі `js-game-progress`, `js-game-drafts`).

## Структура

```
index.html          — Екран 1: карта світу (+ розділи «Проєкти» і «Трофеї»)
levels/level.html   — Екран 2: проходження місії (?id=N)
css/style.css       — усі стилі (токени кольорів у :root)
js/storage.js       — робота з localStorage
js/levels.js        — масив усіх 96 рівнів + опис 11 локацій
js/game.js          — спільна логіка: розблокування, XP, рівень героя, трофеї
js/art.js           — процедурний піксель-арт (карта, герой, сцени, предмети)
js/ui.js            — спільні іконки, бокове меню, підсвітка коду
js/checker.js       — пісочниця й перевірка відповідей усіх типів завдань
js/app.js           — рендер карти, проєктів і профілю
js/mission.js       — рендер і логіка екрана місії
tests/run.html      — службова сторінка: проганяє еталонні рішення всіх рівнів через checker
assets/mockups/     — референс-макети
```

## Як перевіряються відповіді

| Тип | Перевірка |
|---|---|
| `predict-output` | кожен рядок виводу порівнюється окремо (без урахування пробілів, лапок навколо і регістру) |
| `multiple-choice` | обраний варіант = `expectedAnswer` |
| `fill-blank` | вміст пропуску без пробілів = одному з допустимих варіантів |
| `write-function`, `fix-code` | код виконується через `new Function` у пісочниці: `try/catch`, захист від безкінечних циклів, підставні `document` / `localStorage` / `fetch` / таймери; далі проганяються `testCases` і `codeChecks` |

Щоб переконатися, що всі рівні коректні, відкрий `tests/run.html`: для кожного рівня еталонне рішення має проходити перевірку, а стартовий код — ні.
