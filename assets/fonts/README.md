# Sidebar wordmark font

`roboto-slab-cyrillic-800.woff2` is the Cyrillic subset for **Roboto Slab**, weight 800. It is served by Google Fonts (`robotoslab` v36) and used only by the sidebar wordmark.

Roboto Slab is a licensed slab-serif approximation of the approved wordmark lettering; it is not claimed to be the exact typeface in the reference image. Google Fonts metadata lists the family as a serif with Cyrillic and Cyrillic Extended subsets and an Apache 2.0 license.

- Family metadata: <https://github.com/google/fonts/blob/main/apache/robotoslab/METADATA.pb>
- License text: [RobotoSlab-LICENSE.txt](RobotoSlab-LICENSE.txt)
- CSS source for the served subset: <https://fonts.googleapis.com/css2?family=Roboto+Slab:wght@800&subset=cyrillic>
- WOFF2 source: <https://fonts.gstatic.com/s/robotoslab/v36/BngbUXZYTXPIvIBgJJSb6s3BzlRRfKOFbvjoDIOma2RjRdE.woff2>

The font file is unmodified. Its license is included alongside it.
